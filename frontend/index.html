Lectura del recorrido

Una interfaz pensada para que la decision pedagogica aparezca en primer plano

1. Diagnostico inicial Una entrada corta para estimar rapidamente el punto de partida del estudiante.
2. Ruta sugerida Recursos y siguientes pasos organizados por necesidad detectada.
3. Seguimiento docente Indicadores, alertas y evidencia para decidir si intervenir, sostener o cerrar.

La composicion mezcla tono institucional, tablero de producto y lenguaje editorial para hacer mas memorable el MVP.
